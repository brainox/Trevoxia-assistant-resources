# Trevoxia Assistant Resources

Commands, source code, tests, and supporting resources for the Trevoxia AI Assistant build series.

This repository is the learning companion for the daily YouTube videos. Each lesson contains the commands shown in the video, the exact code built during the lesson, and a completed project that you can run locally.

## What we are building

Over four weeks, we will build a production-ready AI assistant step by step:

| Week | Focus |
| --- | --- |
| 1 | Python foundations, LLM fundamentals, chat, and memory |
| 2 | Tool calling, RAG, integrations, and a simple agent workflow |
| 3 | Multi-agent architecture, autonomous workflows, long-term memory, and opportunity detection |
| 4 | Authentication, logging, monitoring, and deployment |

## How to use this repository

1. Open the folder for the lesson you are watching.
2. Follow its `README.md` in order.
3. Copy the terminal commands from `COMMANDS.md`.
4. Compare your work with the `completed-project` folder.
5. Run the lesson tests before moving to the next day.

Clone all course resources with:

```bash
git clone https://github.com/brainox/Trevoxia-assistant-resources.git
cd Trevoxia-assistant-resources
```

## Repository roles

- **This repository:** organized learning materials that accompany each video.
- **[`trexovia-assistant`](https://github.com/brainox/trexovia-assistant):** the evolving application built throughout the course.

## Requirements

- Python 3.9 or newer
- Git
- A terminal
- A code editor such as Visual Studio Code
- An OpenAI API key beginning with Day 3

## Getting help

If a command or code sample does not work:

1. Compare your files with the lesson's `completed-project` folder.
2. Confirm `python` and `python -m pip` point to the same virtual environment.
3. Run the compile check before the automated tests.
4. Open a GitHub issue and include the lesson, command, error message, operating system, and Python version.
